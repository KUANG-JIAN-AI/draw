# 空中ジェスチャーお絵かきボード

MediaPipe Hands を使用したフロントエンドのジェスチャーお絵かきボードです。カメラを使ったハンドジェスチャーによる描画、色の選択、線の太さ変更、消しゴム、元に戻す、全消去、保存に対応しています。

## 実行方法

1. 仮想環境を作成して有効化（推奨）

```bash
cd /Users/kyo/Projects/python/draw

python3 -m venv venv

source venv/bin/activate
```

2. 依存パッケージをインストール

```bash
pip install -r requirements.txt
```

3. 設定ファイルを準備

```bash
cp .env.example .env
```

その後、`.env` を編集します。

```dotenv
OPENAI_API_KEY="あなたの OpenAI API Key"
```

4. Flask アプリケーションを起動

```bash
python app.py
```

5. ブラウザで開く

```text
http://127.0.0.1:5000
```

ポート 5000 が使用中の場合は、別のポートを指定できます。

```bash
python app.py --port 5001
```

## 複数人での共同作業

クライアントは Socket.IO を使用して同じルームに接続し、描画、全消去、元に戻す操作をリアルタイムで同期できます。

新しいユーザーが参加した際には、現在のキャンバスの描画履歴が自動的に送信されます。

## AI 画像生成

簡単なイラストを描いた後、「AI 生成」をクリックします。カメラを起動し、手を握って中央メニューを開くと、スタイル、サイズ、モデルを切り替えられます。生成後は原画と生成結果が並んで表示されます。

后端读取项目根目录 `.env` 中的 `OPENAI_API_KEY`。保存后重启服务即可生效。点击「AI 生成」会将白底草图和风格提示发送至 OpenAI 的 `/v1/images/edits`，默认使用 GPT Image 2.5 Flare，每次生成一张中等质量的 PNG，费用计入该密钥所属的 API 项目。也可在手势工具栏切换到 GPT Image 2.5 Sunburst。

原有小组配置仍可使用。只设置 `AGNES_API_KEY` 时使用 Agnes，同时配置两个密钥时优先使用 OpenAI。

4. ブラウザで開く

```text
http://127.0.0.1:5000
```

ポート 5000 がすでに使用されている場合は、別のポートを指定できます。

```bash
python app.py --port 5001
```

デバッグモードを有効にする場合：

```bash
python app.py --debug
```

## 協作與操作說明

- 未加入房间时绘画仅保存在当前页面；加入房间会载入该房间画布。
- 切换房间会退出原房间；断线期间暂停同步绘画，重连后重新载入服务器历史。
- 撤销以完整笔画为单位，仅撤销当前连接自己的操作；清空也可以撤销。
- 房间历史保存在内存中，最后一位成员离开或服务器重启后释放。需要保留的内容请先下载。
- 每个房间最多保留 30,000 个绘画线段；达到上限后请保存并清空。清空保留一份可恢复的历史。
- AI 面板可由顶部按钮展开；摄像头开启后，同一按钮可关闭摄像头。
- 图片保存接口仅接受 PNG、JPEG、WebP data URL，不接受远程地址；请求体上限 16 MiB，单图上限 10 MiB。
- AI 生成按来源 IP 限制为每分钟一次。公网部署仍需在入口配置用户认证和用量配额。

验证协作逻辑：`python -m unittest discover -s tests -v`

## 画布缩放

画布右下角的 − / + 按钮可缩放，点击百分比恢复 100%，「适应窗口」完整显示画布。
在画布区域滚动鼠标滚轮或使用触控板滚动，可围绕指针位置缩放（5%–400%）。
面板内部保留普通滚动。缩放仅影响本地视图，不影响协作坐标、保存图片或 AI 输入的尺寸。
缩放逻辑测试：`node --test tests/zoom.test.mjs`。

开启摄像头后，双手各自捏合拇指和食指，拉开双手放大，靠近缩小。
松开任意一只手结束缩放；只保留一只手在镜头中即可继续绘画。
双手同时出现时暂停绘画与工具悬停选择，避免缩放时误操作。中央工具菜单打开时，双手缩放也会暂停。


## 手势操作（中文）

开启摄像头后，尽量让整只手保持在镜头中央。右侧常驻手势工具栏已改为中央快捷菜单；顶部工具栏仍可用鼠标操作。

| 操作 | 手势／方法 |
| --- | --- |
| 画画／抬笔 | 单手拇指与食指捏合画画，松开即抬笔。 |
| 打开中央工具菜单 | 先松开捏合约 0.2 秒，再握拳保持约 0.5 秒。也可点击画布上方的「工具」。 |
| 选择工具 | 松开拳头，用食指指向按钮并停留约 0.8 秒；按钮显示选择进度。选择时不要捏合。 |
| 换颜色、粗细、精细模式、填色、橡皮、撤销、保存 | 在菜单中选择，完成后自动关闭菜单。填色／精细模式再次选择可关闭。 |
| 调整 AI 风格、尺寸、模型 | 停留选择以循环切换，菜单保持打开；离开按钮后再次停留可继续切换。 |
| AI 生成／清空 | 选择后显示确认界面；生成会显示当前风格、尺寸和模型。选择「确认」执行并关闭，选择「取消」返回菜单。 |
| 不选择任何工具，关闭菜单 | 松开拳头后再次握拳约 0.5 秒，或停留选择「返回画画」。鼠标点击「工具」或按 Esc 也可关闭。 |
| 关闭菜单后继续画 | 先松开捏合，再重新捏合落笔，避免菜单操作带出线条。 |
| 移动画布 | 菜单关闭时，张开手掌移动。 |
| 缩放画布 | 菜单关闭时，双手各自捏合拇指和食指，拉开放大、靠近缩小。只保留一只手后恢复单手操作。 |

光标颜色：红色表示捏合绘画，绿色表示悬停／张掌移动，紫色表示识别到握拳，选中按钮时为黄色。捏合时其余三根手指可以伸直，不会因此切换为张掌拖动。识别到握拳时，上方显示开关菜单的百分比进度；若提示先张掌，请先展开手掌片刻再握拳。

菜单打开时暂停绘画、填色、画布拖动和双手缩放。持续握拳只触发一次，必须松拳后才能再次触发；画画中的捏合不会直接触发开菜单。手离开镜头或出现双手时会取消当前手势计时，菜单保留，回到单手后可以继续选择。

防抖默认「适中」，可在顶部选择关闭或加强；防抖越强，笔尖响应越慢。精细模式让绘画时笔尖移动减半，松开捏合可重新摆位，但不会自动连接上一笔端点。区域填色使用当前颜色，指向封闭区域捏合一次即可；有缺口会填到外部，可用撤销恢复。初次打开页面会完整显示画纸。

## ジェスチャー操作（日本語）

カメラを起動し、手全体がなるべく画角の中央に収まるようにしてください。右側の常設ジェスチャーツールバーは中央のクイックメニューに変更しました。上部ツールバーはマウスでも操作できます。

| 操作 | ジェスチャー／方法 |
| --- | --- |
| 描画／ペンを上げる | 片手の親指と人差し指をつまむと描画、離すと描画を停止します。 |
| 中央ツールメニューを開く | つまみを約0.2秒解除してから、手を約0.5秒握ります。キャンバス上部の「ツール」をクリックしても開けます。 |
| ツールを選択 | 握った手を開き、人差し指をボタンに約0.8秒重ねます。選択の進行状況が表示されます。選択中はつままないでください。 |
| 色、線の太さ、精密モード、塗りつぶし、消しゴム、元に戻す、保存 | 選択すると適用され、メニューが自動で閉じます。精密モードと塗りつぶしは再選択で解除できます。 |
| AIのスタイル、サイズ、モデル | ボタンに指を重ねると順に切り替わり、メニューは開いたままです。指を離して再び重ねると次の設定に切り替わります。 |
| AI生成／全消去 | 確認画面が表示されます。AI生成では現在のスタイル、サイズ、モデルを確認できます。「確認」で実行して閉じ、「キャンセル」でメニューに戻ります。 |
| 選択せずに閉じる | 一度手を開いてから、再び約0.5秒握ります。「描画に戻る」の選択、「ツール」のクリック、Escキーでも閉じられます。 |
| メニューを閉じた後の描画 | つまみを一度解除してから、再びつまんで描き始めます。 |
| キャンバス移動 | メニューを閉じた状態で、手のひらを開いて動かします。 |
| キャンバスのズーム | メニューを閉じた状態で両手の親指と人差し指をそれぞれつまみ、両手を離すと拡大、近づけると縮小します。片手だけを映すと片手操作に戻ります。 |

カーソルの色：赤はつまみ描画、緑はホバー／開いた手での移動、紫は握った手の認識、黄はボタン選択です。つまんでいる間は他の3本の指を伸ばしていてもキャンバス移動には切り替わりません。手を握ると上部にメニュー開閉の進行率が表示されます。手を開くよう案内が出た場合は、一度手のひらを開いてから握ってください。

メニュー表示中は描画、塗りつぶし、キャンバス移動、両手ズームを停止します。握り続けても開閉は一度だけで、再操作には手を開く必要があります。描画中のつまみから直接メニューが開くことはありません。手が見えなくなった場合や両手が映った場合は、ジェスチャーの待機時間をリセットします。メニューは表示したままなので、片手に戻せば選択を続けられます。

手ぶれ補正は初期設定で中程度です。上部から無効または強に変更できます。補正を強めるとペン先の追従が遅くなります。精密モードでは描画中のペン先の移動量が半分になります。つまみを解除すると手を置き直せますが、前の線の端には自動接続しません。塗りつぶしは現在の色を使用し、閉じた領域を一度つまむと適用されます。輪郭に隙間があると外側にも広がるため、「元に戻す」で取り消してください。ページを開くと用紙全体が表示されます。

フロントエンドのテスト：`node --test tests/*.test.mjs`。サーバーのテスト：`venv/bin/python -m unittest discover -s tests -v`。
